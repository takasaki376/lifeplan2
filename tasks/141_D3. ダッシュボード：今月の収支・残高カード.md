# Jiraチケット（D3）ダッシュボード：今月の収支・残高カード（MonthlyRecordから集計）

## Summary

D3. ダッシュボード：今月の収支・残高カード（MonthlyRecord から集計）

## Issue Type

Story（または Task）

## Priority

High（ダッシュボードのコアKPI）

## Background / Context

D1（plan/currentVersion）・D2（今月ステータス）に続き、ダッシュボードで「今月の状況」が一目で分かるようにする。
MVPでは月次は「かんたん入力」で合計値を保存するため、MonthlyRecord（当月）の値から収支・残高を表示する。

## Goal

- 当月 MonthlyRecord を取得し、今月の収入/支出/収支を表示できる
- 資産残高/負債残高（必要なら純資産）を表示できる
- 未入力の場合は空状態を表示し、最短CTA（今月を入力）へ誘導できる
- 数値は共通フォーマット（A5）で一貫表示する

---

## In Scope

- 画面：`/plans/[planId]`（ダッシュボード）
- Repo連携：
  - `MonthlyRepo.getByYm(planId, currentYm)`
- 表示カード（v0モック準拠）：
  - 今月の収入（incomeTotalYen）
  - 今月の支出（expenseTotalYen）
  - 今月の収支（income - expense）
  - 資産残高（assetsBalanceYen）
  - 負債残高（liabilitiesBalanceYen）
  - （任意）純資産（assets - liabilities）
- 空状態/未入力時の導線：
  - `今月を入力` → `/plans/[planId]/months/current`
  - `月次一覧` → `/plans/[planId]/months`
- ローディング/エラー表示（最小）

## Out of Scope

- 前月比・前年差分の計算（将来：D3+）
- 収支の内訳（詳細内訳の集計：E6以降）
- 自動計算/イベント反映（E5 / I2）
- グラフ（トレンド）表示

## Functional Requirements

### 1) 当月キー（currentYm）の生成

- `currentYm = getCurrentYearMonth()`（A5）
- 表示ラベル：`formatYearMonth(currentYm)`（例：2026年1月）

### 2) MonthlyRecord取得

- `record = await MonthlyRepo.getByYm(planId, currentYm)`
- recordが無い場合（未入力）：
  - カードは「未入力」状態を表示
  - 数値は `—`（または 0）を表示（方針を統一：推奨は `—`）
  - Primary CTA：`今月を入力`

### 3) 集計値（MVP最小の算出）

- income = record.incomeTotalYen ?? 0
- expense = record.expenseTotalYen ?? 0
- net = income - expense
- assets = record.assetsBalanceYen ?? 0
- liabilities = record.liabilitiesBalanceYen ?? 0
- netWorth（任意） = assets - liabilities

※未入力では record 自体が無いので、上記は表示しない or `—`。

### 4) 表示ルール

- 金額表示はA5の `formatYen()` を使用
- 収支（net）は符号で視認性を変える（任意だが推奨）
  - net >= 0：プラス（緑系）
  - net < 0：マイナス（赤系）
- “概算/入力値”であることの注記（任意）
  - `※入力された合計値に基づく表示です`

### 5) 導線

- カード右上（または下部）に配置：
  - `今月を編集`（recordあり）→ `/months/current`
  - `今月を入力`（recordなし）→ `/months/current`
  - `月次一覧` → `/months`

### 6) ローディング/エラー

- ローディング：Skeleton（カード領域）
- エラー：toast or カード内Alert（他カードに影響させない）
  - `今月データの取得に失敗しました`
